## Screenshots — what to capture

Take them on your phone (power + volume-down), then drop the PNGs into
`docs/store-assets/screenshots/`. Your build has real streak/progress data, which looks
much better in the listing than a fresh install's empty states.

Shoot in this order — the first two are what most people actually see in the store:

1. **Today dashboard** — with the GoalRing part-filled and a live streak.
2. **A lesson exercise mid-answer** — ideally a translate or multiple-choice step.
3. **Review / SRS** — a flashcard with cards due.
4. **The level journey** — the A0→B2 progress map.
5. **AI tutor chat** — a short exchange in Croatian (Learn tab).
6. *(optional)* Quiz results or a mock-exam screen.

Requirements Play enforces: PNG or JPEG, portrait 9:16-ish, each side between 320 and
3840 px. A native phone screenshot already satisfies all of this — **do not crop or resize**.

Avoid in-frame: the status bar clock reading something odd, notification badges, and any
personal content in the AI chat.

Once they're in the folder, ask Claude to check dimensions and draft the per-screenshot
caption text for the listing.


## Framed listing images (`play/`)

`python tools/store/make_store_shots.py` turns the raw captures into 1080x1920 listing images:
brand background, caption, device bezel. Re-run it after replacing any screenshot.

**It never edits the screenshot itself.** Play requires listing images to show the real app, so
the phone content is the untouched capture and everything added lives outside the bezel. If you
want different wording, edit the `SHOTS` table at the top of that script; the order there is the
upload order, and Play shows the first few largest.

The background is the app's DARK theme, not the website's light one, because these captures are
dark and a dark UI floating on pale paper reads as a mistake.

### Still worth capturing

1. **Review tab (the hub, not a card)** — the to-review / started / mastered row with the pack
   list. The set currently shows one flashcard but never the system behind it.
2. **A quiz or mock exam** — the listing claims a path to the official exam, and nothing in the
   images shows one.
3. **Profile with both languages** — every shot is Croatian, so nothing proves Portuguese exists.
4. *(optional)* **The light theme** — all eight are dark; some people choose on that alone.
